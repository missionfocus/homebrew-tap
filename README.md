# homebrew-tap

Homebrew tap for Mission Focus command line tools.

```sh
brew install missionfocus/tap/videlicet
```

## videlicet

The operator CLI for [Videlicet](https://github.com/missionfocus/edc): administers Gemini
batch jobs and loads page scans into a running app. macOS only.

`Casks/videlicet.rb` is generated by GoReleaser from a `v*` tag on `missionfocus/edc` —
don't edit it by hand. Because that repository is private, Homebrew can't download its
release assets, so the signed and notarized macOS archives are mirrored onto **this**
repository's releases, tagged `videlicet-v*`.
